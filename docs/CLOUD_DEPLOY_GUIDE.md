# 🚀 Пошаговое Руководство: 24/7 Автономный Облачный Мониторинг и Синхронизация CSV

> **Назначение:** Запуск бота в бесплатном облаке (Render.com) для непрерывного мониторинга ликвидаций и сирены, пока выключен свет, с автоматической синхронизацией `pnl_and_points_analysis.csv` и `config.json` на твой ПК.

---

## 📋 Как устроена система (Кратко)

1. **В облаке (Render.com, тариф Free):** Бот работает 24/7. Каждые 15 секунд сканирует котировки Lighter и Polymarket, вычисляет буфер до ликвидации и отправляет алерты/сирены в Telegram.
2. **Анти-сон (UptimeRobot):** Бесплатный сервис пингует эндпоинт `https://твой-сервис.onrender.com/health` каждые 5 минут. Бот отвечает `200 OK`, благодаря чему бесплатный сервер никогда не засыпает.
3. **Когда ты закрываешь/открываешь позиции со смартфона (`/o`, `/c`):** Бот производит расчёты, обновляет `config.json`, дописывает строку в `pnl_and_points_analysis.csv` и **моментально отправляет коммит в твой GitHub репозиторий** через GitHub REST API.
4. **Когда дали свет и ты включил ПК:** Ты вводишь одну команду `npm run sync`, и все свежие строки из облака за 2 секунды скачиваются в твой локальный файл `pnl_and_points_analysis.csv`.
5. **Когда мы пишем новый код в Antigravity:** Ты вводишь `npm run deploy` — скрипт прогоняет тесты, подтягивает свежий CSV из облака и пушит код в GitHub. Render автоматически перезапускается со свежей версией.

## 🔑 Шаг 1. Создание GitHub токена (Fine-grained PAT)

Токен нужен облачному боту, чтобы коммитить обновления CSV в твой приватный репозиторий без ввода логина и пароля.

1. Открой GitHub и нажми на свою аватарку в правом верхнем углу → **Settings** (Настройки).
2. В левом меню прокрути в самый низ и нажми **<> Developer settings**.
3. В меню слева выбери **Personal access tokens** → **Fine-grained tokens**.
4. Нажми кнопку **Generate new token**.
5. Заполни поля:
   * **Token name:** `Lighter-Cloud-Worker`
   * **Expiration:** выбери срок действия (например, `90 days` или `1 year`).
   * **Resource owner:** твой аккаунт (`Swager2k1`).
   * **Repository access:** выбери **Only select repositories** → в выпадающем списке выбери репозиторий **`Swager2k1/Lighter`**.
6. В разделе **Permissions** раскрой **Repository permissions**:
   * Найди пункт **Contents** → измени доступ на **Read and write**.
   *(Все остальные права оставь No access — это гарантирует максимальную безопасность).*
7. Прокрути вниз и нажми зеленую кнопку **Generate token**.
8. **Скопируй токен** (он начинается на `github_pat_...`) и временно сохрани в блокнот.

## ☁️ Шаг 2. Бесплатное развертывание на Render.com

1. Перейди на сайт [render.com](https://render.com) и нажми **Get Started for Free** (войди через свой аккаунт GitHub).
2. На главной панели (Dashboard) нажми кнопку **New +** в правом верхнем углу и выбери **Web Service**.
3. В списке репозиториев найди свой репозиторий **`Lighter`** (или `Swager2k1/Lighter`) и нажми **Connect**.
4. Заполни параметры сервиса:
   * **Name:** `lighter-monitor` (или любое удобное имя).
   * **Region:** выбери любой европейский регион (например, `Frankfurt (EU Central)`).
   * **Branch:** `main`.
   * **Root Directory:** оставь пустым.
   * **Runtime:** `Node`.
   * **Build Command:**
     ```bash
     npm install && npm run build
     ```
   * **Start Command:**
     ```bash
     npm start
     ```
   * **Instance Type:** выбери **Free** ($0 / month).

## 🔐 Шаг 3. Добавление секретов (Environment Variables) в Render

Не нажимая пока Deploy, прокрути чуть ниже до раздела **Environment Variables** (Переменные окружения) и добавь следующие ключи (нажимая *Add Environment Variable*):

| Key (Имя переменной) | Value (Значение) | Описание |
| :--- | :--- | :--- |
| **`TELEGRAM_BOT_TOKEN`** | `78489...` *(твой токен)* | Токен основного инфо-бота от @BotFather |
| **`CRITICAL_TELEGRAM_BOT_TOKEN`** | `85721...` *(твой токен)* | Токен бота-сирены от @BotFather |
| **`TELEGRAM_CHAT_ID`** | `123456789` *(твой ID)* | Числовой ID чата Telegram |
| **`GITHUB_PAT`** | `github_pat_...` | Токен, созданный на Шаге 1 |
| **`GITHUB_REPO`** | `Swager2k1/Lighter` | Имя репозитория |
| **`GITHUB_BRANCH`** | `main` | Ветка репозитория |
| **`PORT`** | `8080` | Порт для healthcheck-сервера |
| **`DISABLE_POLLING`** | `false` | В облаке поллинг обязательно включен (`false`) |

После заполнения всех переменных нажми внизу кнопку **Deploy Web Service** (или **Create Web Service**).  
Render начнет сборку (`npm install && npm run build`) и через 1-2 минуты запустит бота.

В логах на странице сервиса ты увидишь:
```
[HealthServer] Сервер проверки доступности запущен на порту 8080
📌 Активные рынки: TSM (или нет)
🟢 Монитор запущен!
```
А в Telegram тебе придет приветственное сообщение от бота.

Скопируй адрес твоего сервиса сверху страницы Render (он имеет вид `https://lighter-monitor-xxxx.onrender.com`).

## ⏰ Шаг 4. Настройка UptimeRobot (Защита от засыпания)

Бесплатные сервисы Render засыпают, если к ним 15 минут нет входящих HTTP-запросов. Чтобы бот работал 24/7 без пауз, подключим бесплатный пингер.

1. Перейди на [uptimerobot.com](https://uptimerobot.com) и зарегистрируй бесплатный аккаунт.
2. В панели управления нажми **+ Add New Monitor**.
3. Заполни поля:
   * **Monitor Type:** `HTTP(s)`
   * **Friendly Name:** `Lighter Monitor Health`
   * **URL (or IP):** `https://твой-сервис.onrender.com/health`  
     *(Обязательно добавь `/health` в конце URL)*
   * **Monitoring Interval:** выбери `Every 5 minutes` (Каждые 5 минут).
4. Нажми **Create Monitor**.

Теперь UptimeRobot будет пинговать роут `/health` каждые 5 минут. Сервер будет мгновенно отдавать `200 OK`, и Render будет держать бота активным 24 часа в сутки, 7 дней в неделю!

## 💻 Шаг 5. Повседневная работа (Шпаргалка для ПК)

### 1. Настройка локального `.env` на твоем компьютере
Чтобы локальный бот на ПК не мешал облачному боту (исключая ошибку Telegram 409 Conflict):
Открой свой локальный файл `.env` в корне проекта на ПК и добавь/измени строку:
```bash
DISABLE_POLLING=true
```
*(Теперь при локальной разработке или тестах поллинг на ПК не запускается, а облачный бот спокойно работает).*

---

### 2. Сценарий «Включили свет после блэкаута»:
Ты проснулся или дали свет после 4-часового отключения. За это время ты мог закрывать позиции через Telegram-бота, и они записались в облаке.
Просто открой терминал в папке проекта и выполни:
```bash
npm run sync
```
*Что произойдет:* Git аккуратно скачает свежий `pnl_and_points_analysis.csv` и свежий `config.json` прямо в твою рабочую папку без каких-либо конфликтов. Ты сразу можешь открыть файл CSV в Antigravity и анализировать PnL.

---

### 3. Сценарий «Мы написали новый код и хотим обновить облачного бота»:
Мы с тобой в Antigravity добавили новую фичу или поправили логику расчета. Чтобы безопасно выкатить обновление:
Выполни в терминале одну команду:
```bash
npm run deploy
```
*Что произойдет автоматически:*
1. Скрипт проверит компиляцию TypeScript (`npm run typecheck`).
2. Прогонит полный набор автотестов (`npm test`).
3. Подтянет самые свежие строки CSV из облака (`git pull --rebase --autostash origin main`).
4. Отправит код в GitHub (`git push origin main`).
5. Render увидит новый коммит в GitHub и сам за 30 секунд обновит бота в облаке!

## 🛡️ Безопасность и Конфиденциальность

* **Репозиторий:** Приватный. Никакие адреса, транзакции или CSV не видны никому в интернете.
* **Токен:** Ограничен только репозиторием `Lighter` и правами Contents.
* **Веб-эндпоинт:** Путь `/health` отдает только слово `OK`. Доступ к файловой системе, переменным окружения или логам через веб-порт полностью заблокирован.
* **Устойчивость к сбоям:** Если интернет пропадет прямо во время записи CSV, бот сохранит локальную копию и повторит попытку при следующем действии.
